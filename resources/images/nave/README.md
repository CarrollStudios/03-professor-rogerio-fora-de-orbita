Sprites em pixel art da nave, usados pelas classes `CenaDecolagem`, `CenaMeteoro` e `PecaNave`. A nave fica numa pasta própria porque aparece em várias telas. As 6 peças são as que o jogador recupera nas 3 fases (2 peças por fase).

| Arquivo | O que é |
|---|---|
| `nave.png` | Nave de pé, vazia |
| `nave-com-aluna.png` | Nave de pé, com o rosto da aluna na janela |
| `nave-lado.png` | Nave de lado, com o bico para a direita (entrando pela porta) |
| `nave-fogo-1.png` e `nave-fogo-2.png` | Fogo do motor (os dois desenhos se alternam para piscar) |
| `nave-peca-bico.png` | Peça 1: bico |
| `nave-peca-janela.png` | Peça 2: janela |
| `nave-peca-corpo.png` | Peça 3: corpo (rachado, sem a janela) |
| `nave-peca-asa-esquerda.png` | Peça 4: asa esquerda |
| `nave-peca-asa-direita.png` | Peça 5: asa direita |
| `nave-peca-motor.png` | Peça 6: motor |
