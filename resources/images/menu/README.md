Imagens em pixel art usadas pela classe `TelaMenu`. Tamanho da tela: 1280 × 720.
O menu é animado: cada elemento é uma camada separada (fundo transparente), e o código faz os planetas, os asteroides e a nave flutuarem, e o meteoro atravessar a tela de vez em quando.

| Arquivo | O que é |
|---|---|
| `menu-fundo-espaco.png` | Céu com as estrelas (parado) |
| `menu-meteoro.png` | Meteoro (atravessa a tela a cada 7 segundos) |
| `menu-planeta-laranja.png`, `menu-planeta-azul.png`, `menu-planeta-verde.png`, `menu-planeta-lilas.png`, `menu-planeta-anel.png` | Planetas (flutuam) |
| `menu-asteroide-1.png`, `menu-asteroide-2.png`, `menu-asteroide-3.png` | Asteroides (flutuam) |
| `menu-nave.png` | Nave (balança) |
| `menu-planeta-rosa-superficie.png` | Chão do planeta rosa (parado, na frente) |
| `titulo-menu.png` | Título "Professor Rogério / Fora de Órbita" |
| `botao-jogar.png`, `botao-jogar-hover.png` | Botão Jogar (normal e com o mouse em cima) |
| `botao-sair.png`, `botao-sair-hover.png` | Botão Sair (normal e com o mouse em cima) |
