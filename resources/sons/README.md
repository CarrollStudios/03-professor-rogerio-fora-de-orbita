Sons originais, criados do zero com código no estilo 8-bit (sem direitos autorais de terceiros). Formato **WAV**, que o Java toca sem precisar instalar nada. Quem toca os sons é a classe `Sons` (em `src/jogo`).

## musicas
Tocam em loop (recomeçam sozinhas quando acabam).

| Arquivo | Onde toca |
|---|---|
| `musica-escola.wav` | Menu, corredor e sala (alegre, com bateria) |
| `musica-espaco.wav` | Decolagem, meteoro e próximas telas no espaço (calma e misteriosa) |

## efeitos
Tocam uma vez, na hora da ação.

| Arquivo | Quando toca |
|---|---|
| `clique.wav` | Clique nos botões |
| `passo-1.wav` e `passo-2.wav` | Passos da aluna (um para cada pé) |
| `porta.wav` | Porta do LAB 3 abrindo |
| `fala-letra.wav` | Letrinhas aparecendo na caixa de fala |
| `nave-voando.wav` | Nave entrando na sala |
| `raio.wav` | Raio puxando a aluna para a nave |
| `decolagem.wav` | Nave decolando |
| `batida.wav` | Asteroide batendo na nave |
| `pecas.wav` | Peças da nave se espalhando |
